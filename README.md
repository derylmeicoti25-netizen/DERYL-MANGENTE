# Website UMKM - Kripik Renyah

Selamat datang di repositori proyek website landing page UMKM **Kripik Renyah**. Website ini dirancang khusus untuk mempermudah calon pembeli melihat produk dan terhubung langsung ke WhatsApp penjual.

---

## 🏗️ Arsitektur Website

Website ini menggunakan struktur halaman tunggal (*Single Page Application / Landing Page*) yang efisien:

```text
                     [ Home / Landing Page ]
                                |
      +-------------------------+-------------------------+
      |                         |                         |
[ Katalog Produk ]       [ Tentang Kami ]         [ Kontak & Lokasi ]
      |                                                   |
 (Informasi Harga)                                  (Pemesanan WA)
```

---

## 👤 User Story

1. **Skenario 1: Pembeli Langsung Pesan**
   - **Sebagai** pengguna / calon pembeli,
   - **Saya ingin** mengklik tombol *Pesan via WhatsApp* di halaman utama,
   - **Agar** dapat langsung berkomunikasi dengan penjual tanpa harus mendaftar akun.

2. **Skenario 2: Melihat Daftar & Harga Produk**
   - **Sebagai** pengguna,
   - **Saya ingin** melihat pilihan varian rasa beserta harganya di menu *Produk*,
   - **Agar** dapat memilih camilan yang sesuai dengan selera dan anggaran saya.

3. **Skenario 3: Mencari Alamat Toko Fisik**
   - **Sebagai** pelanggan lokal,
   - **Saya ingin** mengetahui informasi alamat dan jam operasional toko pada bagian *Kontak*,
   - **Agar** bisa datang dan membeli secara langsung di lokasi toko.
